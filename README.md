# 🐾 UniPatas

Sistema em desenvovimento em Java utilizando Maven.

Projeto acadêmico sobre adoção de animais, focado em persistência em memória secundária utilizando RandomAccessFile.

- Model
- DAO
- Controller

## 💾 Persistência
Armazenamento em arquivo binário (.db)
